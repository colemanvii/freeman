## Generation prompt

Create a single photographic contact sheet for a construction-record interaction prototype. Layout is EXACTLY 2 columns by 2 rows, four equal landscape photographs with NO gaps, borders, captions, typography or labels. Each panel is exactly the SAME fixed tripod perspective of a modest restaurant interior detail: a large timber semicircular arched radius window centered in an old pale plaster wall, brick reveals, grey concrete floor, daylight and greenery beyond the glass. Architecture editorial documentary photography, soft daylight, restrained natural colors, tangible materials, imperfect working site. The camera position and window dimensions MUST match across all four panels. Top left: stripped opening, exposed brick arch and rough wall, temporary timber bracing, dusty floor, a few offcuts. Top right: custom unfinished timber arched frame installed, a carpenter's workbench in lower left, masking on glass, rough exposed reveals, modest tools. Bottom left: plaster reveals newly repaired, glass installed with tape at edges, sill fitted, floor protection and a folded cloth, still visibly unfinished. Bottom right: completed pale plaster reveals and sealed warm timber radius window, clean room, subdued daylight, simple timber bench below window. No furniture styling except bench, no luxury magazine glamour. These are illustrative concept images, not a representation of a documented real building. Output high resolution 3072x2048 contact sheet so each quadrant is 1536x1024. Keep identical framing across all panels.
