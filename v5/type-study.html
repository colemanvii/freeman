Three typographic systems for the phone, set on the real entrance and Projects pages.

Each direction is the same pages, the same content, the same colours and the same signature. Only the type changes: face, weight, size, tracking, leading, case and the strength of secondary text. Every frame below is the live site code running at an exact iPhone viewport.

On a phone, use OPEN FULL SCREEN under each direction: it opens that direction as the real site, where you can tap through. The choice follows you between pages until you open another.

05 — Recommendation

C, Fragment Mono: one face, one weight, set like a monograph.

  1. The signature stays the only voice. C is the quietest of the three in colour and the firmest in form. A single regular weight cannot compete with the bitmap script, yet its Helvetica stems hold the line beneath it in a way Courier New's hairlines and Plex's SemiBold did not.
  2. Authority from proportion, not weight. Swiss grotesque capitals are the lettering of architectural publishing and signage. Set in a fixed-width cell they keep the site's monospaced discipline — the thing Monaco gave the approved design — without the terminal associations of Menlo or Plex.
  3. Hierarchy the way a monograph builds it. Project names in their own title case at 16.5px; credits, places and labels in true small caps. Three levels, one weight, no extra tracking: the hierarchy comes from size, case and colour alone.
  4. One system, reliably delivered. 28 KB, self-hosted, identical on every phone. Entrance, section line, index and credits all speak the same face.

If C is too far a step, B is the dependable alternative: it fixes legibility and contrast everywhere and stays entirely in capitals, but it remains IBM's voice rather than Freeman's.

Before production: confirm C on a physical iPhone; decide on title-case names (C also works with names in capitals); extend the system to Company, Contact, project pages and Map; and decide whether desktop later follows, so phone and desktop share one face.
