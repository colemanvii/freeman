# Freeman Studies

Small project-led investigations into architecture, construction, hospitality, landscape and material.

A study can begin with a house, detail, architect, hotel, golf development, room, landscape condition, or construction problem.

Each study should answer four questions:

1. What is worth noticing?
2. Why does it work?
3. What would Gabe say about building it?
4. What can Freeman learn without copying it?

## First study

**Gabe's Cabin / Fay Jones**

Focus:
- sheltering roof
- threshold
- integrated cabinetry
- structure as atmosphere
- relationship to site

Desired artifact:
one loose exterior drawing, one simple plan, one interior/millwork study, Gabe's redline, and a short note on what survives into a Freeman version.
