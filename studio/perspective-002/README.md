# Freeman / Perspective 002: Visual direction

The visual direction for the Perspective programme, made to be approved before the full deck for Tristan is polished. Twelve plates, read top to bottom; ↑ ↓ page between them.

- `index.html`: the page (built). `src.html`: the source. `tools/build.py`: inlines the production signature and eagle bitmaps from `release/approved-v5-2026-10-18`, so the marks are never redrawn.
- `img/`: resized copies of photographs from Freeman's published portfolio, credited as Freeman publishes them. Beetlecat, The Optimist and Barnsley are by Jared Swafford. The Woodlands at Barnsley Resort photographer is to be confirmed. The Ruskin page comes from the Freeman archive (`v5/etcetera/ruskin.webp`).
- Every "To be shot" frame is a plan. None is an image of Freeman work, and no image here is generated.
- Reference works (plate 07) are cited, not reproduced. Frames from them should be placed only from licensed or public-domain sources. This study session could not reach external image hosts.
- Nothing in `v5/` or on the live site was changed.

Rebuild from the repo root: `python3 studio/perspective-002/tools/build.py`
