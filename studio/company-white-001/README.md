# Company 001 — Architectural White

Study branch `study/company-white-001`, cut from production (`origin/release/approved-v5-2026-10-18`).
Not production. Preview: `/company.html` on the branch's gated Pages preview.

The Company page as four plates, turned like a monograph's front matter:
01 Philosophy · 02 Services · 03 People · 04 Work.

- White ground and umber ink from the approved Architectural White entrance; orange only marks the current plate and a hovered link.
- 12-column field: the plate's name holds columns 1–3, the material starts at column 4.
- Philosophy: one monumental sentence, three columns, signed with the original bitmap signature.
- Services: a three-line schedule; one photograph in the margin (Barnsley Family Pool).
- People: set as credits, role then name. No headshot placeholders.
- Work: the project record (records.js) as an index of works; each line opens the project.
- Paging: PREV / NEXT, arrow keys, swipe on phones, or the contents line at the foot; `?sheet=n`.

Copy is production's own, except the Paul Nair / Savi Provisions quote, which comes from the
previous freemangc.com (`brutalist/data/company.js`) and isn't on the live site. Confirm before shipping.

Typography: production currently sets everything in Libre Franklin (American Gothic). This preview
turns that off (`v5/american-gothic/toggle.js`) so the whole preview reads in Monaco.

Files: `v5/app.js` (company()), `v5/styles.css` (block "Company 001"), `v5/american-gothic/toggle.js`.
