## What it explores

One page, three modes, four role perspectives.

- **See** — role-specific figures, signals, and project register.
- **Ask** — sample answers tied to sample source passages, including contradictions, access limits, and missing information.
- **Act** — capture field observations, attach photographs or supported browser dictation, assign an owner, and move a decision through a visible trail.
- **Owner / controller / project manager / superintendent** — role changes in the demo are a visual simulation, not secure authorization.

Identity: Freeman's quiet institutional typography, chalk paper, hairlines, and restrained signal color. The strength of this pass is evidence-backed decision flow. The next challenge is a more distinctive and enjoyable interaction model.

## What is mocked

**All project records, people, figures, schedules, and financial details are fictional demonstration material.** No figures here are verified against Freeman's real books.

There is no model or real-time retrieval. Answers are scripted, with keyword fallback; edits persist only in this browser's `localStorage`. There is no shared database, Procore or BuildingConnected integration, accounting feed, or secure role enforcement.

**Do not** treat this as an authenticated staff tool or connect real project records to this public repository.
